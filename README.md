## Описание:
Десктопное приложение для автоматизации работы библиотек. Представляет собой оболочку над базой данных, предназначенную для хранения и управления информацией о произведениях, изданиях, читателях и т.д.

## Функционал:
- Авторизация под одной из трех ролей: "Библиотекарь", "Администратор библиотеки", "Администратор библиотечного фонда"
- Регистрация, просмотр, удаление, редактирование библиотек
- Регистрация, просмотр, удаление, редактирование библиотекарей
- Регистрация, просмотр, удаление, редактирование читателей
- Добавление читателя в категорию ("Студенты", "Преподаватели", "Школьники", "Пенсионеры", "Научные работники"), удаление из категории, просмотр читателей, относящихся к категории
- Регистрация, просмотр, удаление, редактирование произведений
- Регистрация, просмотр, удаление, редактирование изданий
- Выдача изданий читателю / возврат изданий в библиотеку
- Списание изданий

## Технологии:
> Java, Spring, PostgreSQL, JavaFX
